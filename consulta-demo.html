Cómo se incorpora al CRM

Dos archivos y una línea. En la página del CRM (HtmlService): 
<div id="consulta"></div>
<script src="https://hlorca-maker.github.io/voz-refrichile/motor.js"></script>
<script src="https://hlorca-maker.github.io/voz-refrichile/consulta.js"></script>
<script>
  VozConsulta.montar(document.getElementById('consulta'), {
    api: 'https://script.google.com/macros/s/…/exec',   // la API de voz
    clave: '<?= claveVoz ?>',                          // clave personal de quien está conectado
    alAbrirCliente: function (rut) { abrirFichaCrm(rut); } // opcional
  });
</script>
  • Responde desde los datos guardados en el teléfono (productos, precios, stock, cartera, cotizaciones, pendientes): en milisegundos y también sin señal.
  • Lo que se guarda (recordatorios, tareas, "hecha") se envía por detrás con reintentos seguros; el CRM lo ve en Tareas pendientes.
  • Toma los colores del CRM (--primary, --surface, …) y se adapta a claro/oscuro.
  • Micrófono: donde el navegador lo permita, dicta ahí mismo; dentro del marco de Apps Script (bloqueado) el botón abre la app de voz.
  • Lo que la copia local no resuelve va a la IA de la API (si está configurada).
